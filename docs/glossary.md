# Domain Glossary / 领域术语表

> 状态：Phase 0 草案（WM-0002）
> 来源：《Wavemaker 完整技术设计与实施计划》§1.2「领域术语」。本表只收录计划书明确给出的术语，不引入计划书之外的新概念。
> 约定：术语保留英文原词；定义中英双语；「不应混淆为」栏来自计划书原文。

| 术语 | 定义（中） | Definition (EN) | 不应混淆为 / Do not confuse with |
|---|---|---|---|
| Wavemaker | 整个压测框架 | The load-testing framework as a whole. | 单个 Worker / a single Worker |
| Swell | 一次完整压测实验及其生命周期 | One complete load-test experiment and its lifecycle. | 单个任务命令 / a single task command |
| Spectrum | 描述负载形状、到达过程、行为分布和生命周期的配置 | The configuration describing load shape, arrival process, behavior distribution, and lifetime. | 单个 Bot 脚本 / a single Bot script |
| Basin | 被测环境及其服务拓扑、服务端观测配置 | The environment under test, its service topology, and server-side observability configuration. | Prometheus 本身 / Prometheus itself |
| Controller | 控制面，负责计划生成、任务管理、分配和报告编排 | The control plane: plan generation, task management, allocation, and report orchestration. | Actor 执行器 / an Actor executor |
| Worker | Wavemaker 管理的执行节点 | An execution node managed by Wavemaker. | 必然等同于一个 Actor / necessarily identical to one Actor |
| Execution Backend | 实际生成负载的执行实现 | The execution implementation that actually generates load. | 进程管理器 / a process manager |
| Native Runtime Backend | Wavemaker 自己的 Rust 执行后端 | Wavemaker's own Rust execution backend. | 游戏引擎原生 Bot / engine-native Bots |
| Engine Bot Backend | 复用引擎自带 Bot 的执行后端 | An execution backend that reuses the game engine's own Bots. | Wavemaker Actor / a Wavemaker Actor |
| Supervisor | 管理 Backend 进程/容器生命周期的组件 | The component managing Backend process/container lifecycle. | 游戏引擎内部调度器 / the engine's internal scheduler |
| Bridge | 引擎侧与 Wavemaker 之间的控制/事件/指标适配层 | The control/event/metrics adaptation layer between the engine side and Wavemaker. | 仅仅是网络代理 / a mere network proxy |
| Actor | Native Runtime 中的虚拟客户端 | A virtual client inside the Native Runtime. | 所有引擎原生 Bot 的统一对象 / a unified object for all engine-native Bots |
| ShardPlan | Controller 生成并冻结的执行计划分片 | An execution plan shard generated and frozen by the Controller. | Worker 自行生成的计划 / a plan generated by the Worker itself |
| Generator Observability | 压测发生器自身的资源和运行状态观测 | Observability of the load generator's own resources and runtime state. | Basin 服务端监控 / Basin server-side monitoring |
| Server Observability | 被测服务端的指标采集和时间序列 | Metric collection and time series of the server under test. | Generator 指标 / Generator metrics |

## 补充：Spectrum 子术语（来源：计划书 §8.1 / §8.2.1）

以下术语来自计划书 §8，是 BLOCKER-1 语义闭合（见 `docs/spec/spectrum-semantics.md`）的一部分，同样保留英文原词。

| 术语 | 定义（中） | Definition (EN) |
|---|---|---|
| Arrival Model | Bot 到达过程 | The Bot arrival process. |
| Concurrency Constraint | 并发目标或上限 | A concurrency target or cap. |
| Lifetime Model | Bot 生命周期概率分布 | The probabilistic distribution of Bot lifetime. |
| Behavior Model | 行为组合 | The composition of behaviors. |
| Workload Model | 请求/消息和业务负载特征 | Request/message and business load characteristics. |
| Fault Model | 故障注入策略（如启用） | Fault injection policy (if enabled). |
| `arrival.target_rate` | 目标到达速率 | The target arrival rate. |
| `concurrency.target` | 希望达到的并发目标（可选） | The desired concurrency target (optional). |
| `concurrency.max` | 硬性并发上限（可选） | The hard concurrency cap (optional). |
| `saturation_policy` | 达到 `concurrency.max` 后的处理方式 | The policy applied once `concurrency.max` is reached. |
